# MSS54HP CSL '0401' — 微開（足を乗せただけ）の「ぐわんぐわん」

対象症状：**アクセルペダルに足を乗せる程度の微開**で、ギアが繋がったまま低速で転がしているとき、
車体が大きく・ゆっくり前後に揺すられる。舵を切るとこれが強まり、デフを引きずるように感じる。

これは [`low_rpm_steering_judder.md`](low_rpm_steering_judder.md) で解決した「ガクガク」
（速くて細かい、`kf_rf_soll_tau_up` で消えた）とは**別の現象**である。周波数が違い、原因が違い、対策が違う。

---

## 0. 結論

1. **アイドルバルブではない。** このECUのアイドルバルブはフィードバックを一切持たない開ループで、
   暖機後は回転数によらずほぼ一定デューティ（≈21 %）で固定されている。**振動源になりえない。**
2. **アイドル回転制御器（LFR）でもない。** 走行中（2 km/h 以上・クラッチ締結）は P 項と点火項が
   強制ゼロ、積分項も約 970 rpm を超えると 5 Nm 以下に減衰する。権限が残っていない。
3. **VE（`kf_rf_soll`）で合っている。ただし「値」ではなく「回転数方向の傾き」。**
   微開では**エンジン回転数そのものが充填量センサとして使われている**。その換算則の傾きが
   1200 rpm 付近で物理より緩く、1300–1700 rpm で物理の 2 倍以上に急になり、**サージの回転数帯の
   真ん中で誤差の符号が反転する。** これが揺れにエネルギーを注ぎ込む。

## 1. 微開で空気はどこを通っているか

`aq_rel_calc` @ `f:master:01ac7a`（code-confirmed）：

```c
aq_abs_wdk = klu_wint(&KL_AQ_ABS_WDK.sizeX, WDK_SEGM);
AQ_ABS     = AQ_ABS_LLS + aq_abs_wdk;
AQ_REL     = (AQ_ABS - K_AQ_ABS_MIN) * 0x8000 / (K_AQ_ABS_MAX - K_AQ_ABS_MIN);
aq_rel_rf  = AQ_REL << 15 / aq_rel_rf_fakt;          // aq_rel_rf_fakt = kl_aq_rel_rf_fakt(N)
```

スロットルとアイドルバルブは**直列ではなく並列**で、開口面積を足し算している。
スロットル開度 1.2 %、暖機後のアイドルバルブとして（data-confirmed の曲線から computed）：

| 経路 | 開口面積 | 全体に占める割合 |
|---|---|---|
| スロットル板 `KL_AQ_ABS_WDK(1.2 %)` | 9.8 mm² | 65 % |
| アイドルバルブ `KL_AQ_ABS_LLS(21.4 %)` | 5.3 mm² | 35 % |
| **合計 `AQ_ABS`** | **15.1 mm²** | （`K_AQ_ABS_MAX` = 11918 mm² の 0.127 %） |

**微開はアイドルバルブだけの領域ではない。** スロットルの方が多い。ただし両者とも
「空気量を測っている」のではなく「開口面積から推定している」点が本質である。

> `k_aq_rel_wdk_segm_nullage` = 0.3 % の不感帯は `EGAS_SOLL == 0`（ペダル全戻し）のときだけ
> 効く。足を乗せている間は関係ない（code-confirmed）。

## 2. アイドルバルブは振動源になりえない

`llr_qvs_roh_calc` @ `f:master:0257d2` → `llr_qsoll_calc` @ `f:master:0258da`
→ `lls_tv_calc` @ `f:master:025d0a`（すべて code-confirmed）：

```
LLR_QVS_ROH = KF_LLR_QVS_GRUND(N, TMOT)        // 回転数と水温だけの表
LLR_QVS     = PT1(LLR_QVS_ROH, LLR_TAU_QVS)
LLR_QSOLL   = LLR_QVS + K_LLR_Q_MCS            // K_LLR_Q_MCS = 0.0 kg/h
LLS_TV      = KF_LLS_TV(N, LLR_QSOLL) + UB補正 // UB補正は KL_LLS_UB_KORR 全点ゼロ
```

**どこにも回転数偏差も負荷偏差も入っていない。** 入力は回転数と水温だけで、しかも（data-confirmed）：

| 定数 / 表 | アドレス | 値（XDF 表示） |
|---|---|---|
| `KF_LLR_QVS_GRUND` の TMOT 80 °C 行 | 0xA064 | 600 / 900 / 1350 / 3000 / 5000 rpm すべて **14.0 kg/h** |
| `K_LLR_Q_MCS` | 0xA048 | 0.0 kg/h |
| `K_LLR_QSOLL_MIN` | 0xA0AE | 0.0 kg/h |
| `KL_LLS_UB_KORR` | 0x9DC5 | 全 5 点 **0.0**（電圧補正なし） |
| `K_LLS_TV_DREHPUNKT` | 0x9DB6 | 30.08 %（動作点 21 % より上 → 補正分岐に入らない） |

暖機後の動作点は `KF_LLS_TV(N, 14.0 kg/h)` → **500 rpm で 21.4 %、1400 rpm で 21.5 %、
1700 rpm 以上で 22.3 %**（computed）。回転数に対してほぼ平坦。

> 結論：デューティは定数である。定数は揺れない。
> **ただし**、実際のバルブ流量が `KL_AQ_ABS_LLS` の想定からずれていれば、それは**定常オフセット**に
> なる。微開では総面積の 35 % を占めるので、±2 mm² のずれで RF 推定が ±5 % 動く（computed）。
> これは揺れの原因ではなく、**揺れを起こす急勾配域に動作点を押し込む**方向に効く。

## 3. アイドル回転制御器（LFR）も犯人ではない

`lfr_calc` @ `f:master:0266b8`（code-confirmed）。走行中の経路を辿ると：

- `s_kraftschluss_calc` @ `f:master:01d558`：**`V > K_LLR_V_MAX`（2.0 km/h）で `S_KRAFTSCHLUSS = 1`。**
  クラッチスイッチではなく車速で決まる。
- `lfr_calc` L93–97：`S_KRAFTSCHLUSS != 0 && V > K_LFR_V_MAX`（2 km/h）で
  **`LFR_MDP = 0`、`LFR_MD_TZ = 0`。** P 項も点火項も死ぬ。
- `LFR_DN = LFR_N_N_SOLL - N`（`llr_n_soll_calc` @ `f:master:026db8` の戻り値、code-confirmed）。
- 状態機械：`LFR_ZUSTAND` は 2（閉ループ）→ TL/VL に入った瞬間に 4（発進補助）→
  **`N > LFR_N_N_SOLL + K_LFR_DN_HYS` で 0x10。**
  暖機後 `KL_LFR_NSOLL_GRUND(80 °C)` = 870 rpm、`K_LFR_DN_HYS` = 100 → **しきい値 970 rpm。**
  （A/C 作動中は `K_LFR_NSOLL_AC` で目標が持ち上がり、しきい値も同じだけ上がる）
- 状態 0x10 では `LFR_I_AFR = 0`、`LFR_MDI` は `K_LFR_UEW_MAX` = **5.0 Nm** を上限に
  `K_LFR_TAU_IA2_KS` = 0.32 s で減衰する。

**970 rpm を超えたら LFR の持ち分は 5 Nm 以下。** ぐわんぐわんを作れる量ではない。

> 副次的に見つかった欠陥：状態 4 ⇄ 0x10 の**往復しきい値が同一値（970 rpm）で、ヒステリシスが無い**
> （L49 と L66 がどちらも `K_LFR_DN_HYS + LFR_N_N_SOLL` と比較している、code-confirmed）。
> 970 rpm 近傍で状態が毎周期反転しうる。ただし両状態とも `MD_LLRI` はほぼゼロなので、
> 現状の較正では実害が出ない。**この症状の原因ではない。**

## 4. ぐわんぐわんの仕組み

MAF が無いので（`k_rf_hfm_cfg` = 0）、DME は空気量を測っていない。**開口面積と回転数から推定している。**

```
スロットル開度 + アイドルバルブ  →  AQ_ABS  →  AQ_REL
AQ_REL ÷ kl_aq_rel_rf_fakt(N)    →  aq_rel_rf
kf_rf_soll(N, aq_rel_rf)         →  RF（充填率）
RF                               →  噴射量（KF_TI_N_RF）とトルクモデル
```

回転数が 2 か所に入っている。つまり**回転数の変化がそのまま充填量推定の変化になる。**

開口が小さいとき、物理はこうである：**微小開口は絞り（ほぼ臨界流）なので、通過する質量流量は
回転数にほとんど依存しない。1 サイクルあたりの充填量は回転数に反比例する。**

> 1 サイクル充填量 = 質量流量 ÷（回転数 / 2） ∝ 1 / N
> すなわち両対数の傾き **d(ln RF)/d(ln N) = −1.00** がこの領域の正解。

較正がこの −1.00 からどれだけずれているかが、**回転数の揺れに対するループゲインの過不足**そのものになる。

- 傾きが **−1.00 より緩い**（例 −0.6）＝ 回転が上がっても充填推定を十分下げない → 燃料とトルクを出しすぎる → **回転がさらに上がる**
- 傾きが **−1.00 より急**（例 −2.1）＝ 回転が上がると充填推定を下げすぎる → 薄くしてトルクを落としすぎる → **回転が落ちすぎる**

片方だけなら定常誤差で済む。**両方が隣り合って並んでいると、揺れが回転数帯を往復するたびに
誤差の符号が反転し、揺れに位相の合った力が毎周期加わる。** これがぐわんぐわんである。

## 5. 数字 — 較正の傾き vs 物理

スロットル開度を固定して回転数だけ動かしたときの d(ln RF)/d(ln N)（BIN から computed、正解は −1.00）：

| rpm | WDK 1.2 % | WDK 2 % | WDK 3 % | WDK 5 % | WDK 8 % |
|---:|---:|---:|---:|---:|---:|
| 1100 | −0.89 | −0.95 | −0.94 | −0.91 | −0.55 |
| **1200** | **−0.57** | **−0.74** | **−0.75** | −1.03 | −1.03 |
| 1300 | −1.34 | −1.31 | −1.21 | −1.06 | −1.21 |
| **1400** | **−2.14** | **−1.62** | **−1.50** | −1.15 | −1.06 |
| 1500 | −1.79 | −1.20 | −1.25 | −1.18 | −1.01 |
| 1600 | −1.26 | −1.31 | −1.30 | −1.28 | −0.84 |
| **1700** | **0.00** | −1.46 | −1.35 | −1.34 | −0.60 |
| 1800 | −0.63 | −1.28 | −1.12 | −1.12 | −0.67 |

読み方：

- **WDK 1.2 % の列だけ振れ幅が桁違い。** 1200 rpm の −0.57 から 1400 rpm の −2.14 まで、
  200 rpm の間に傾きが 3.8 倍になり、1700 rpm でゼロに戻る。**振れ幅 2.14。**
- WDK 5 % では −1.03 〜 −1.34（振れ幅 0.31）、WDK 8 % ではさらに平坦。
  **この欠陥は微開にしか存在しない。** 症状が微開だけに出ることと一致する。
- 誤差の符号は 1250 rpm 付近で反転する。1300–1700 rpm は、標準ファイナル 3.62・245/40R18 で
  **1 速 10–13 km/h、2 速 17–22 km/h、3 速 26–34 km/h**（computed）。
  **交差点を曲がる・駐車場を転がす、そのままの速度帯である。**

スロットル開度方向の感度も同時に見ておく（computed）：

| WDK | 開度 +0.1 % で RF が動く量 |
|---:|---:|
| 1.2 % | **+2.11 %** |
| 3 % | +1.57 % |
| 8 % | +1.81 % |
| 13 % | +0.27 % |
| 20 % | −0.01 % |

微開はスロットル方向にも 8 倍敏感である。舵を切って PAS ポンプが回転数を揺らすと、
その揺れがこの 2 つの急勾配で同時に増幅される。**舵を切ると悪化する理由はここにある。**

## 6. 決定的なセル — 1600 rpm の逆転

`kf_rf_soll (CSL Alpha-N)` @ 0xD356、XDF 表示値（data-confirmed）：

| aq_rel_rf ＼ rpm | 1100 | 1300 | 1400 | **1600** | 1800 | 2100 |
|---:|---:|---:|---:|---:|---:|---:|
| 0.0977 % | 0.113 | 0.095 | 0.092 | **0.088** | 0.075 | 0.050 |
| 0.1465 % | 0.132 | 0.126 | 0.105 | **0.084** | 0.085 | 0.074 |
| 0.1953 % | 0.147 | 0.134 | 0.118 | 0.104 | 0.090 | 0.079 |
| 0.3906 % | 0.209 | 0.192 | 0.178 | 0.156 | 0.140 | 0.133 |

**1600 rpm の列で、開口を 0.0977 % から 0.1465 % に増やすと充填率が 0.088 → 0.084 に下がる。**
開口を増やして空気が減ることは物理的にありえない。全表 480 セルのうち、低負荷域でこの逆転が
起きているのはこの 1 か所だけである（computed、`kf_rf_soll` 全セル走査）。

同じ行（0.1465 %）の区間別の傾き：

| 区間 | 1100→1300 | 1300→1400 | 1400→1600 | 1600→1800 | 1800→2100 |
|---|---:|---:|---:|---:|---:|
| d(ln RF)/d(ln N) | −0.28 | **−2.46** | −1.67 | **+0.10** | −0.90 |

緩すぎ → 急すぎ → 符号反転、が 1 行の中に並んでいる。隣の行（0.1953 %）は
−0.55 / −1.72 / −0.95 / −1.23 / −0.85 で、物理に近い。**行 0.1465 だけが壊れている。**

そして微開の動作点はこの行に乗る（computed）：

| rpm | WDK 1.2 % の aq_rel_rf | 行 0.1465 % の重み |
|---:|---:|---:|
| 1400 | 0.158 % | 76 % |
| 1600 | 0.149 % | 95 % |
| 1800 | 0.141 % | 88 % |

**微開・1400–1800 rpm では、充填量推定の 8〜9 割が表の中で最も壊れた 1 行から来ている。**

## 7. なぜ `kf_rf_soll_tau_up` の修正はガクガクだけ消したのか

`rf_soll_calc` @ `f:master:01a9d2` の PT1 は `kf_rf_soll_tau_up(N, RF)` で係数を引く
（`f:master:01a5d6` L17、code-confirmed）。y 軸は **RF**（充填率）で、微開の RF は 8〜18 %
＝ **行 0.1**と行 0.3 の下側。まさに変更した行である。

一次遅れは**速い揺れを削り、遅い揺れは素通しする**。XDF 表示 0.5 → 0.6（k = 0.500 → 0.400、
セグメント同期）では折点が約 5 Hz。

| 揺れの周期 | 減衰 |
|---|---|
| 4 セグメント（速い＝ガクガク） | −23 % |
| 40 セグメント（遅い＝ぐわんぐわん） | **−2 %** |

**ガクガクが消えてぐわんぐわんが残ったのは、対策が周波数を選んだからであって、原因が別だからではない。**
同じ表の同じ領域の、別の周波数成分である。遅い方を同じ手で消すには折点を 1 Hz 付近
（XDF 表示 ≈ 0.91）まで下げる必要があり、それではアクセル操作そのものが鈍る。
**遅い方はゲインを削るしかない。＝表の形を直す。**

## 8. 焼く前に測ること

XDF を書き換える前に、動作点の前提（スロットル開度 1.2 %）を実測で潰す。
必要な RAM は `mss54hp-csl-convert-tuner` の `ramMap.ts` に定義済み：

| 信号 | アドレス | 換算 | 見るもの |
|---|---|---|---|
| `WDK_WORD` | 0x00FFECF8 | ×0.1 % | **最重要。** 微開で実際に何 % か |
| `WDK_SOLL` | 0x00FFE6FE | ×0.1 % | 指令値。`WDK_WORD` との差が 1.0 % を超えると別の系が凍る |
| `LLS_TV` | 0x00FFEF00 | ×0.02 % | 21 % 前後で一定か（動いていたら本稿の前提が崩れる） |
| `LLR_QVS` | 0x00FFEF16 | ÷40 kg/h | 14.0 kg/h で一定か |
| `MD_LLRI` | 0x00FFD8F0 | ×0.1 Nm | 5 Nm 以下か（§3 の確認） |
| `LFR_ZUSTAND` | 0x00FFEA38 | — | 4 か 0x10 か（970 rpm 近傍で往復していないか） |
| `EVAN1_IST` / `AVAN1_IST` | 0x00FF81DC / 0x00FF81DA | — | **カムが目標に追従しているか。** 低負荷の VE は残留ガスで決まるので、VANOS が遅れていれば表の前提自体が崩れる |

判定：

- `WDK_WORD` が微開で **1〜3 %** → 本稿の診断がそのまま当てはまる。§9 へ。
- `WDK_WORD` が **5 % 以上** → 傾き異常は軽い（表の WDK 5 % 列）。別の原因を探す。
- `LLS_TV` が微開で動いている、または 21 % から大きく外れる → §2 の前提が崩れる。先にそこを解く。
- `EVAN1_IST` が `KF_EVAN1_SOLL` に追従していない → **表を触る前にカムを直す。**
  追従していない状態で表を合わせ込むと、直った後に全部ずれる。

## 9. 書き換え値（XDF 表示）

対象：`kf_rf_soll (CSL Alpha-N)` @ 0xD356（z の換算は `x/1000`、表示分解能 0.001）

方針：**1100 rpm と 1800 rpm のセルは動かさない**（定常の燃調レベルを保つ）。
その間の 1300 / 1400 / 1600 だけを、両端が決める一定の傾きに乗せ直す。

| aq_rel_rf 行 | 1300 rpm | 1400 rpm | 1600 rpm |
|---:|---|---|---|
| **0.0977 %** | 0.095 → **0.098** | 0.092 →（据置） | 0.088 → **0.083** |
| **0.1465 %** | 0.126 → **0.114** | 0.105 → **0.106** | 0.084 → **0.094** |
| **0.1953 %** | 0.134 → **0.124** | 0.118 → **0.116** | 0.104 → **0.101** |
| **0.3906 %** | 0.192 → **0.182** | 0.178 → **0.172** | 0.156 → **0.154** |

結果（computed）：

| rpm | 傾き（WDK 1.2 %）変更前 → 変更後 |
|---:|---|
| 1200 | −0.57 → **−1.10** |
| 1400 | −2.14 → **−1.12** |
| 1600 | −1.26 → **−1.01** |
| 1700 | 0.00 → **−1.02** |

振れ幅 **2.14 → 0.17**。1600 rpm 列の逆転は解消（0.083 → 0.094 → 0.101 → 0.154、単調増加）。

定常の燃調への影響は限定的（両端固定のため）：

| 動作点 | RF 変更前 → 変更後 |
|---|---|
| 1100 rpm / WDK 1.2 % | 14.25 % → 14.25 %（±0） |
| 1300 rpm / WDK 1.2 % | 12.96 % → 11.85 %（−8.6 %） |
| 1600 rpm / WDK 1.2 % | 8.50 % → 9.43 %（+11.0 %） |
| 1800 rpm / WDK 1.2 % | 8.38 % → 8.38 %（±0） |

**もっと小さく始めるなら：行 0.1465 % の 3 セルだけ（0.114 / 0.106 / 0.094）。**
微開 1400–1800 rpm の重みの 8〜9 割がこの行なので、これだけで大半が動く。

### 触らないこと

| パラメータ | 理由 |
|---|---|
| `kl_aq_rel_rf_fakt`（0xE058 / 0xE070） | 1300→1400 rpm の刻みが 100 rpm しかなく **6.67 %/100rpm** と隣接区間（3.1〜3.6）の 2 倍だが、傾き異常への寄与は約 1/5（−1.44 のうち −0.26、computed）。かつ**全負荷域の負荷軸そのもの**を動かすので、微開の症状のために触るには代償が大きい |
| `KF_LLR_QVS_GRUND` / `KF_LLS_TV` | §2 のとおり開ループ。下げるとスロットルが開いて動作点は多少マシになるが、アイドル安定性を直接損なう |
| `kf_rf_soll_tau_up` をさらに上げる | §7 のとおり遅い揺れには効かず、アクセル応答だけ失う |

## 10. 確定できなかったこと

- **微開での実スロットル開度。** 本稿の 1.2 % は `KL_BZ_WDK_LL`（アイドル判定しきい値 1.2 %）と
  面積表からの推定であって、実測ではない。**§8 の `WDK_WORD` で潰すこと。**
- **ぐわんぐわんの実周波数。** 本稿は「速い／遅い」の相対関係しか使っていない。
  周波数が分かれば §7 の減衰量を定量できる。
- **`KF_RF_N_AQ_REL`（スロットル指令側の逆引き表）。** この XDF の定義（0x1F98）は
  軸が明らかに別領域を指しており使えない。復元コードにも参照が無い。
  **逆引き表が `kf_rf_soll` と一致していない場合、同じ誤差がスロットル指令側にも二重に乗る**が、
  現状それを検証する手段が無い。
- **`kf_rf_soll` の 1300 / 1400 列が全負荷域で平坦・逆転していること**（1300 列は開口 5 %→30 % で
  単調減少、1400 列は 7.5 %→20 % で 0.667 固定）。測定面ではなく人為的な平滑化に見えるが、
  意図が分からないので本稿では低負荷 4 行以外に手を付けていない。
- **アイドルバルブの実流量。** `KL_AQ_ABS_LLS` の想定と実機の差は台上でしか分からない。
  定常オフセットとしてのみ効き、揺れの原因ではない（§2）。
