
/*  * sys_cancel_task - Cancels a delayed (scheduled) task if present in the scheduler queue.
    *
    * @param task_id: The ID of the task to cancel (0–31).
    *
    * @return byte: Status code.
    *         - 0x00: Task successfully cancelled.
    *         - 0x22: Task was not scheduled; no action taken.
    *
    * Description:
    * If the given task is currently marked as scheduled (bit 0 set in its control byte),
    * this function searches the scheduler's delay queue (up to 8 slots) to find the task entry.
    * If found, it:
    *   - Clears the task's countdown timer.
    *   - Clears the task ID from the entry.
    *   - Clears the scheduled flag (bit 0) in the task's control byte.
    * 
    * If the task is not marked as scheduled, the function logs an error using `syserror`
    * and returns status 0x22.
    *
    * Interrupts are masked during table modification to ensure thread safety. */
